The work route map for building the gbai framework. One task is one reviewable PR (about 400 changed lines, a planning heuristic only), test-first wherever a runnable deterministic test exists; skill-only tasks are checked by skill review against the named journey. `depends_on` and `unblocks` mirror each other and form no cycle. Tool-specific behavior is never compiled code: Go is only `gbai init`, `gbai check` and `gbai version` (TRD D24, superseding the agent compiler of D18 in part), the user's agent builds the config and the agents from skills, and trackers, memory, notifications, direct sessions, methodology, repository host and reviewer placement live in contract skills and repository adapters (TRD 2, D2). New Go code follows the hexagonal slice shape under `apps/cli/internal/slices/<name>/` (`domain`, `usecase`, `adapters`).
