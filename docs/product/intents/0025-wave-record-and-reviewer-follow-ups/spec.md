- **The findings (a) to (i), intent 0024.** `docs/product/intents/0024-mechanical-wave-steps-and-follow-up-fixes/plan.md`, "Probe results" and "Findings for the owner" (2 to 8), the wave report on [#664](https://github.com/testeos-z/gabo-ai/issues/664#issuecomment-6840017419), the probe comments on [#677](https://github.com/testeos-z/gabo-ai/issues/677), PR [#693](https://github.com/testeos-z/gabo-ai/pull/693) and PR [#694](https://github.com/testeos-z/gabo-ai/pull/694).

- **The planning record.** `gabo-assistant/SKILL.md`, Planning Record: "... `proposals: none`, and the UTC time." The third T5 run on [#637](https://github.com/testeos-z/gabo-ai/issues/637#issuecomment-6837003143) saved `time: 2026-11-12 (UTC).`
- **The reviewer scripts.** `apps/cli/internal/skills/gabo-reviewer/scripts/common.sh`: one state directory and one mirror `repo.git` per machine (`WORKDIR`, line 125), `prune_one` builds `$WORKDIR/worktrees/pr-<n>` and the lock `pr-<n>.lock` from the PR number alone and asks `gh pr view <n> --repo "$REPO"` for its state (line 714); `prune_caches` runs `go clean -cache` and trims `check-home` by age, never `cache/go-mod` ("go-mod is never trimmed"). `config.env`: `REVIEWER_KEEP_DAYS=7`, `REVIEWER_CACHE_MAX=2G`. Measured on the real state, [#677](https://github.com/testeos-z/gabo-ai/issues/677): 361 worktrees of which 74 belong to PRs unknown to `gabo-ai`; caches 1.99G.
- **Version stamp.** `gabo check` fails only when the catalog stamp is newer than the binary (`apps/cli/internal/slices/check/usecase.go`, `checkStamp`); a dev build and an older build of the same release carry the same version, so the check cannot flag the older binary.
- **No overlap with the open intent 0023 (#575).** Its spec covers Pi `--print`, worktree registration, the Pi guardrails file, status labels on closed tasks, the `Refs` keyword and merged remote branches. None of (a) to (j) is in it; the files overlap only (section 5). Nothing was left out for it.
