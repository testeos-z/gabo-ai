Plan items the spec left to `gabo-dev-lead`, answered here:

- **JSONC writes (S2, S3)**: **Proposed (auto)** no new Go dependency: the byte-span scanner `gabo init` already uses for `.claude/settings.json` (`engineconfig/claude.go`: `scanObject`, `skipWS`, `skipValue`, `insertMember`) moves to a shared file and learns to skip `//` and `/* */` comments and trailing commas, plus a `removeMember` that deletes one member and its separating comma. Reason: the TRD stack is the owner's choice (TRD D14), and the scanner already keeps every other byte.
- **Removal pass (S4, D2)**: **Proposed (auto)** `engineconfig.Integrate` gets a cleanup pass over every full-tier engine with a main-session key, declared or not; `initcmd` reads `.claude/settings.json` and the four OpenCode config files whenever they exist. Reason: D2 B removes the gabo value whatever `runtimes.*` says.
- **D3 and D4** are owner questions: T8 and T10 are planned for the proposed answer A and stay BLOCKED until the owner answers; a B answer comes back as a plan-change that amends their rows and adds tasks (see Open questions).
- **Version bump**: not in this plan, on the coordinator's instruction of 2026-11-06.

## Steps

1. Probe whether Claude Code and OpenCode start normally when the default agent is not built yet (T1, D6, spec open question 3). A failing probe stops T2 and T3 and goes to the owner as a plan-change proposal.
2. `gabo init` merges, keeps, refuses and removes the Claude Code `agent` key, with the assistant engine as rule input and the S8 report (T2). Delivers S1, S4 (Claude Code), S8.
3. `gabo init` does the same for OpenCode `default_agent` in the first existing OpenCode config file, comments kept (T3), and raises `experimental.subagent_depth` to at least 3 (T4). Delivers S2, S3, S4 (OpenCode), S8.
4. A Go test keeps the `engineconfig` keys in step with `metadata.main_session` of the runtime skills (T5). Delivers S7.
5. `gabo check` names `gabo init` wherever it is the fix (T6). Delivers S6; this is the `gabo check` update (Q9).
6. The Claude Code and OpenCode runtime skills stop writing engine config keys (T7); the Codex and Pi runtime skills stop removing other engines' keys, waiting on D3 (T8); `gabo-agent-templates`, `gabo-setup` and `gabo-assistant` name `gabo init` as the writer (T9); `gabo-runtime-builder` per D4, waiting on the owner (T10). Delivers S5. Each skill change refreshes its `plugins/codex/skills/` copy in the same PR.
7. The user docs name `gabo init` as the writer and the new hints (T11). Delivers S9.
8. The owner runs `gabo init` in gabo-ai and commits the `agent` key (T12). Delivers S10.
