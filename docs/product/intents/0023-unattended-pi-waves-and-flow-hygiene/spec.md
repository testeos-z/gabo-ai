- **Where `--print` is started today.** `.gabo/skills/gabo-agent-host-local/SKILL.md`, start agent session: the `pi` command is `pi --print --approve --tools read,bash,edit,write,grep,find,ls ...`, and the adapter starts the roles `coder` and `assistant` on Pi. An `assistant` started that way runs a wave in a process that exits after its first turn.
- **What init and check do on Pi today.** `apps/cli/internal/engineconfig/pi.go` `piRule` writes one project file, `.pi/settings.json` (the `packages` entry), and reports the subagent-package refusal only when none is found (intent 0016). `engineconfig` is shared by `gabo init` and `gabo check` and has no ports and no I/O. Neither writes or reads `.pi/gentle-ai/runtime-guardrails.json`. `docs/compatibility.md` (Pi, "Unattended Pi waves need three Pi settings (known limits in 0.2.10)") says gabo does not set these for the owner yet. `gabo check` reports a warning with a leading `! ` and a failure with `✗`.
- **The label and keyword text today.** `.gabo/skills/gabo-contract-tasks/examples/tasks-gh.md` removes `status:in-progress` when it closes a task; the adapter this repository runs (`.claude/skills/gabo-tasks/SKILL.md`) does not, and `gh issue list --state closed --label status:in-progress` returns 92 issues. `.gabo/skills/gabo-coder/SKILL.md` (Hard Rules, and the outcome list) tells the coder to link the task as `Closes #<n>` and admits that on a base that is not the default branch "the keyword closes nothing"; `.gabo/skills/gabo-contract-repository-host/examples/host-github.md` and the contract examples say `Refs #<n>`. `Task Close` (the coder's, D23) is the only writer of DONE.
- **Remote branches.** 35 remote branches of this repository are merged into `origin/dev` today.
