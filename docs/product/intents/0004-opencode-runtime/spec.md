## 2. Design

The change adds one catalog skill, `gabo-runtime-opencode`, that turns the neutral agent spec and templates into OpenCode files, and the small Go and schema changes that let `gabo.yaml` name the runtime. Nothing else in Go changes: `gabo check` already reads `agent_dir`, `skill_dir` and `reviewer_link` from any runtime skill. Build flow: prerequisites and the project-level `experimental.subagent_depth` write (S8) → links in `.opencode/skills` (S5) → probe agent → spec agents in `.opencode/agents` (S3, S4) → stage-gate plugin (S10), a thin layer that invokes the gabo Go hook mode of intent 0001 S11, shared by all four engines → `gabo check`. The S5 link step also links the reviewer-configuration skill (S14).

**Shared reviewer-configuration skill.** Intents 0001 (Claude Code plugin), 0002 (Codex plugin), 0003 (Pi package) and this intent all deliver the same reviewer-configuration skill from one catalog source, with the same behavior in every engine. The plan builds it once (intent 0001 open question 6); this intent only links it (S14, D12).

Tool Map (D3), written as the permission keys an OpenCode agent can deny:

| capability | OpenCode v2 tools | permission keys denied when the spec lacks the capability |
|---|---|---|
| `read` | `read` | `read` |
| `search` | `grep`, `glob` | `grep`, `glob` |
| `edit` | `edit`, `write`, `patch` | `edit` |
| `shell`, `git`, `tracker`, `repository-host` | `shell` | `bash` (and `shell`, if S13 step 10 shows v2 does not alias it) |
| `memory` | MCP tools `<server>_*` of the memory adapter's server (for example `engram_*`) | `<server>_*` |
| `web` | `webfetch`, `websearch` | `webfetch`, `websearch` |
| `skills` | `skill` | `skill` |
| `subagents` | `subagent` | `task` (and `subagent`, as for `shell`) |

Slot fills: `{{methodology}}` is `gabo-methodology`; `{{adapter:<slot>}}` is `gabo-<slot>` with `_` written `-`; `{{reviewer_script}}` is `${XDG_DATA_HOME:-$HOME/.local/share}/gabo/skills/gabo-reviewer/scripts/reviewer.sh`, written literally so the shell expands it and the committed file holds no personal path.
