## Steps

1. The name rule: `checkAgentName` fails an empty declared name with `✗ agent <id> (<runtime>): declares no name`, and the main-session loop runs it for `gabo-assistant`; the help text and the Per-agent checks bullet of `docs/compatibility.md` state it (T1). Delivers S1, S3, S4, S5 (name rule), S6; D1, D2, D4.
2. The listed-twice rule: `compareSkills` returns duplicates apart from extras, including a fixed-name link listed under its link name and its adapter's name, and `checkAgentSkills` prints `missing`, then `listed twice`, then `not in the agent spec`; the help text and the same bullet state it (T2). Delivers S2, S3, S4, S5 (listed-twice rule), S6; D3 to D6.
