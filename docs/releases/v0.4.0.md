## What's new

### Wave flow
- The main session runs the wave with the `gabo-cycle` skill on every engine. The coders run the reviewer script themselves.
- Each wave keys its trace, ledger and stamps by a run id, so a second wave of one intent no longer mixes with the first.
- New config keys cap a wave: `wave.max_coders`, `wave.max_coder_turns` and `wave.max_fix_rounds`. A coder that hits its turn limit stops and reports it.
- A task whose head is clean at the fix round limit is finished, not paused.
- The wave report has a `Measures` section, computed from the wave stamps by `wave-record.sh`.
- Every task closes by removing all of its status labels.
- Pull requests merge into `dev` with a merge commit, never a squash. Task PRs link their task with `Refs #<n>`.

### Pi
- The Pi wave-start warning prints in every session mode. The agent host refuses a Pi assistant session under `--print`.
- The Pi coder takes the model of the engine configuration and has no approval-label gate.
- Each Pi task worktree is registered before its coder starts.
- `gabo init` counts gentle-shell as a Pi subagent package only when `pi list` runs and exits 0. The Pi package installs gentle-pi with npm.

### Reviewer
- The reviewer keeps its caches under `REVIEWER_CACHE_MAX` and prunes `pr-<n>` worktrees of closed or stale PRs.
- Worktrees, locks, caches and the mirror are keyed by repository, so two repositories that share one reviewer state dir no longer collide.
- `gabo init` refreshes the user-level reviewer when its content differs at the same version.

### Config, check and init
- `runtimes.coder` and `runtimes.assistant` accept any well-formed engine name that has a runtime skill. The reviewer still accepts the four engines it runs.
- `gabo check` fails a former agent file that is still on disk, and checks the Pi agent tools.
- `gabo init` no longer writes `experimental.subagent_depth` for OpenCode.
- `autonomousMode` must be a JSON boolean in `init` and `check`.
- Config sync proposes the work-style keys as one diff, saves the local profile and validates remote names before it calls `gh`.

### Direct sessions
- `gabo-direct-sessions-orca` opens and closes sessions on a remote Orca host, and takes any `agent_host` session handle.

## Upgrading

1. Install the CLI:
   ```
   go install github.com/testeos-z/gabo-ai/apps/cli/cmd/gabo@v0.4.0
   ```
2. Run `gabo init` in each project. It writes the reviewer and catalog updates of this release.
3. Ask your agent to rebuild the agents of every engine in `runtimes.*`.
4. Run `gabo check` until it passes. Agent files built before this release may fail until they are rebuilt.

The Pi package is `@gabo-ai/pi@0.4.0`.

Full change list: [`apps/cli/v0.2.10...apps/cli/v0.4.0`](https://github.com/testeos-z/gabo-ai/compare/apps/cli/v0.2.10...apps/cli/v0.4.0).
