0.4.6 follows 0.4.2 with the setup readiness fix below (issue #904).

## What's new

### Setup reports the missing review policy, install step and branch (issue #904)

- `gabo-setup` states that `review.checks` run as argv without a shell in a fresh worktree of the merge result with a clean environment and its own `HOME`, so nothing is installed there. It suggests the lockfile install command (`bun.lock` -> `bun install --frozen-lockfile`, `package-lock.json` -> `npm ci`, `pnpm-lock.yaml` -> `pnpm install --frozen-lockfile`, `yarn.lock` -> `yarn install --frozen-lockfile`) as the first check.
- `gabo-setup` tells the owner that the code read needs `REVIEW.md` on the integration branch (without it the review fails closed with no clean verdict) and offers to scaffold a minimal one, never writing without the owner's answer.
- `gabo-setup` verifies that `repo.integration_branch` exists locally and on the host before writing it, and reports a missing branch instead of accepting it silently.
- `gabo check` fails when the checks use a package manager without an install step. Go-only checks still pass with an unrelated lockfile present.
- The setup output contract lists review readiness (`REVIEW.md`, the install step, the branch) as done, skipped with its reason, or missing.

## Upgrading

1. Install the CLI:
   ```
   go install github.com/testeos-z/gabo-ai/apps/cli/cmd/gabo@v0.4.6
   ```
2. Update the Claude Code and Codex plugins and the Pi package.
3. Run `gabo init` in each project.
4. Ask your agent to rebuild the agents of every engine in `runtimes.*`.
5. Run `gabo check` until it passes.

The Pi package is `@gabo-ai/pi@0.4.6`.
