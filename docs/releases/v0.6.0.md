0.6.0 follows 0.4.8 with intent landing branches, automerge resume and coder worktree cleanup (intents 0031, 0032, 0033, plus the reviewer pour fixes of PR #913).

## What's new

### One landing branch per intent (intent 0032)

- Each intent gets a landing branch named after its folder (`<NNNN-slug>`), cut from `dev`. Task PRs target the intent branch; only the finished intent PR targets `dev`.
- Reverse sync always runs: `<slug>-sync` merges `dev` into the intent branch before the pour, resolved there, never a rebase or force-push.
- Reviewer-side pour proof: a proven pour merges despite task-approved `human_only_paths`; unproven pours and built-in paths (`.gabo/VERSION`, `.gabo/skills/`, reviewer sources) keep the human-only hold. Intent pour commits must each be provably approved (reachable from `dev` or from a merged task/sync PR).

### Automerge resumes after pending review (intent 0031)

- `reviewer.sh resume <pr> <sha>` resumes an interrupted automerge from its pending commit, reusing `merge-head.sh` unchanged instead of re-resolving the merge.

### Coder worktrees cleaned after merge (intent 0033)

- Merged-only removal gate: a coder worktree is removed only when its PR merged into the integration or intent branch; doubt about real unsaved work keeps it.
- Verifier scratch outside the worktree never blocks removal; rebuild-proven `.atl/` content is recyclable, everything else is kept and named.
- Fallback sweep for never-resumed coders: merged worktree, same-wave ledger entry, inactive owner, no Task Close record — evaluated under the same gate without touching task state.

## Upgrading

1. Install the CLI:
   ```
   go install github.com/testeos-z/gabo-ai/apps/cli/cmd/gabo@v0.6.0
   ```
2. Update the Claude Code and Codex plugins and the Pi package.
3. Run `gabo init` in each project.
4. Ask your agent to rebuild the agents of every engine in `runtimes.*`.
5. Run `gabo check` until it passes.

The Pi package is `@gabo-ai/pi@0.6.0`.
